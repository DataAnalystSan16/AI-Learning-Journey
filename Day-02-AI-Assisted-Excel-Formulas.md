# Day 2 — AI-Assisted Excel Formula Practice

## My AI Learning Journey

Today, I practiced using AI to explain, debug, and improve Excel formulas as part of my Data Analytics interview preparation.

### What I Learned
- How the IF function evaluates conditions and returns results.
- How Nested IF formulas evaluate multiple conditions.
- Why the order of conditions matters in Nested IF formulas.
- How to identify and correct formula syntax errors.
- How to test boundary values to verify formula results.

### Practical Exercises
- Asked AI to explain an IF formula in simple terms.
- Identified and corrected a missing closing parenthesis.
- Practiced Nested IF formulas for customer order classification.
- Classified sales performance using monthly sales thresholds.
- Tested boundary values such as 500, 1,000, and 100,000.
- Asked AI to explain formulas step by step and verified the results independently.
