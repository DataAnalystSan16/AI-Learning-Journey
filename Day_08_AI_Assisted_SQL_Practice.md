### Exercises Completed

### Key Learnings
- GROUP BY helps aggregate data based on a specific column.
- ORDER BY sorts query results.
- LIMIT helps retrieve a specific number of rows.
- Understanding the business requirement is essential before writing a SQL query.
- AI can help explain SQL concepts and identify errors.
